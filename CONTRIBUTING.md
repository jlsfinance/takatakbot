# 🤝 Contributing to TakatakBot

Thank you for your interest! Here's how you can help:

## 🐛 Report Bugs
- Open an [Issue](https://github.com/jlsfinance/takatakbot/issues)
- Describe what happened vs what should happen
- Include error logs if possible

## 💡 Suggest Features
- Open a [Discussion](https://github.com/jlsfinance/takatakbot/discussions)
- Describe the feature and use case
- Tag it as `enhancement`

## 🔧 Submit Code

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make changes
4. Test: `setup.bat` should still work
5. Commit: `git commit -m "Add your feature"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## 📝 Style Guide
- Keep it simple — no unnecessary complexity
- Hindi/Hinglish comments allowed
- Test on Windows before submitting

## 🎨 Create a Skill
```bash
nanobot skill create my-skill
```
Then submit a PR adding it to the `skills/` folder.

*Every contribution counts, even a ⭐ star!*
