# TakatakBot 🐈

AI-powered automation bot by **Poojadi (AI Didi)**.

## Features

- PC management & automation
- File analysis & cleanup
- Browser automation
- Telegram assistant
- Coding support
- Business automation
- Stock market analysis
- WhatsApp messaging

## Setup

1. Clone the repo:
   ```
   git clone https://github.com/jlsfinance/takatakbot.git
   cd takatakbot
   ```

2. Run setup:
   ```
   setup.bat
   ```

3. Edit `.env` file with your Telegram bot token

4. Run the bot:
   ```
   venv\Scripts\activate
   nanobot run
   ```

## Requirements

- Windows 10/11
- Python 3.10+
- Git

## Configuration

Edit `config/config.json` to set:
- Telegram bot token
- API keys
- User permissions
- Tool settings
