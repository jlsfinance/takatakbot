# TakatakBot 🐈

AI-powered automation bot by **Poojadi (AI Didi)**.

## Features

- PC management & automation
- File analysis & cleanup
- Browser automation
- Telegram assistant
- Coding support
- Business automation

## Setup

1. Clone the repo:
   ```
   git clone https://github.com/jlsfinance/takatakbot.git
   cd takatakbot
   ```

2. Run setup:
   ```
   setup.bat
   ```

## Requirements

- Windows 10/11
- Python 3.10+
- Git
