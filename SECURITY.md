# 🔒 Security Policy

## Reporting a Vulnerability

Found a security issue? **Do NOT open a public issue.**

Email: jlsfinance@proton.me
Or DM on Telegram: @jlsfinance

We'll respond within 48 hours.

## Best Practices

- Never commit `.env` file to git
- Use unique API keys per installation
- Bot only responds to authorized users
- No registry modifications
- No destructive commands allowed
