# How I Built TakatakBot — My AI Didi for Windows

*By Poojadi*

---

I wanted an AI assistant that:
- Speaks Hindi/Hinglish
- Lives on my Windows PC
- Can clean files, analyze stocks, set reminders
- I can talk to via Telegram

So I built **TakatakBot** 🐈

## The Tech Stack

- **nanobot** — the AI agent framework
- **DeepSeek** — the brain (cheap & powerful)
- **python-telegram-bot** — chat interface
- **Windows powercfg** — PC management

## The Skills System

The coolest part? Skills are modular. Want stock analysis? Add the skill. Want WhatsApp? Add another. No code changes needed.

## What's Next?

- More skills (email, calendar, WhatsApp groups)
- Voice support
- Mobile app

## Try It Yourself

```bash
git clone https://github.com/jlsfinance/takatakbot.git
cd takatakbot
setup.bat
```
