# Product Hunt Listing

## Tagline
Your AI Didi for Windows — PC automation via Telegram

## Description
TakatakBot is a Telegram-powered AI assistant that lives on your Windows PC. Talk to it like a friend in Hindi/Hinglish/English, and it handles your PC tasks — cleaning files, analyzing stocks, managing schedules, coding, browsing, and more.

## Key Features
- 🧹 PC Management: Disk cleanup, large file detection, system reports
- 📈 Stock Market: Nifty 50, Sensex, fundamental analysis
- 💬 Natural Chat: Hindi/Hinglish/English, powered by DeepSeek
- 🛠️ Developer Tools: Code generation, debugging, Git operations
- 📅 Scheduling: Reminders, cron jobs, recurring tasks
- 🔌 Extensible: Modular skills system, easy to add capabilities

## How it works
1. Clone the repo
2. Run setup.bat (asks for API keys)
3. Talk to your bot on Telegram

## Tech
Python, nanobot framework, DeepSeek API, python-telegram-bot
